# DECISIONS — решения, принятые без согласования (по одной строке)

- Название продукта: **BilimLens** (bilim — «знание» по-казахски + lens — «линза»): короткое, читается на RU/KZ/EN, одинаково во всех материалах.
- Палитра: глубокий бирюзово-синий #0B5563 (основной), бирюзовый #14A3A3, тёплый акцент янтарный #E39B2D; статусы: критическая #C2412D, зона риска #E39B2D, норма #5B8DB8, освоена #2E9B6A.
- Шрифт Inter хранится локально (assets/fonts, woff2 cyrillic + cyrillic-ext + latin): в песочнице CDN и Google Fonts недоступны, а сайт должен открываться без интернета; казахские ә ғ қ ң ө ұ ү һ і входят в cyrillic-ext.
- Графики — собственные лёгкие HTML/SVG-компоненты вместо Chart.js: нет зависимости от CDN, корректная печать в PDF, полный контроль подписей на 390px.
- CSV-парсер свой (в analytics.js, покрыт тестами), .xlsx читается через SheetJS 0.18.5, положенный локально в assets/vendor (CDN недоступен в среде сборки; по сути та же библиотека с фиксированной версией).
- Демо-данные подключаются как assets/data/demo.js (window.DEMO_DATA), а не fetch(demo.json): fetch не работает при открытии файла двойным кликом (file://). demo.json тоже генерируется — для внешних инструментов.
- analytics.js оформлен как UMD (window.Analytics в браузере, module.exports в Node): ES-модули блокируются браузером на file://.
- Входной уровень (pre) — диагностический тест по теме в начале четверти, записывается в каждую строку «ученик × тема».
- Сравнение учебников: регрессия post ~ pre + учебник (ANCOVA-упрощение) на уровне ученика; скорректированное среднее — прогноз при среднем pre по выборке; 95% CI по нормальному приближению. Кластеризация по школам не учитывается — это указано в ограничениях.
- «Недостаточно данных»: если у учебника n < 30 или ширина 95% CI разницы > 20 баллов.
- Малые выборки в демо: итоговый тест по теме «Элементы статистики» (конец года) из школ с учебником В сдала только одна малокомплектная школа Мойынкумского района (n < 30).
- Классификация тем: критическая — усвоение < 50% И средний балл ниже медианы средних по темам; зона риска — усвоение < 65%; освоена — усвоение ≥ 85%; иначе норма. Пороги видны в интерфейсе.
- Эффект часов: для каждой темы регрессия post ~ pre + учебник + (факт.часы − план) по ученикам; наклон < 0 обнуляется; добавлять часы можно не больше максимального отклонения, реально наблюдавшегося в данных (не экстраполируем).
- Перераспределение: жадный алгоритм по 1 часу — забираем у освоенных/нормальных тем с наименьшим наклоном (не ниже 70% плана), отдаём критическим/рискованным с наибольшим наклоном, пока выигрыш больше потери; сумма часов не меняется. Сокращение тоже ограничено наблюдавшимся диапазоном (не экстраполируем ни вверх, ни вниз).
- Справочник учебников: «Учебник А/Б/В» (принимаются варианты A/B/C, А/Б/В, «А оқулығы» и т.п.); другие названия при импорте — ошибка «неизвестный учебник» (для пилота справочник расширяется в CONFIG).
- Второй предмет «Физика, 8 класс» (68 ч) добавлен в демо-данные сразу — генератор универсальный.
- gh в среде не авторизован (GH_TOKEN недействителен) → GitHub-репозиторий создать нельзя; публикация — через артефакт claude.ai + dist/standalone.html + dist/site.zip.
